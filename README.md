# BSEB Portal Hub

![License: Proprietary](https://img.shields.io/badge/License-Proprietary%20%2F%20All%20Rights%20Reserved-red.svg)

A unified digital gateway for registrations, exams, scholarships, and educational services in Bihar.

---

## 📋 Overview

BSEB Portal Hub is a fast, searchable directory of official Bihar Board (BSEB) portals, exam forms, syllabus PDFs, and scholarship links. It provides students, educators, and administrators with a centralized resource hub for navigating Bihar's educational ecosystem.

**Live Site:** [BSEB Portal Hub](https://ashish9singh.github.io/bseb/)

---

## ✨ Features

- 🔍 **Live Search** — Instantly filter links by keyword across all categories
- 🌙 **Dark Mode** — Automatic system preference detection with manual toggle
- 📌 **Pinned Favorites** — Save frequently-used links (persisted locally)
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop
- ⚡ **Zero Dependencies** — Pure HTML, CSS, and vanilla JavaScript
- 🎨 **Accessible Design** — WCAG-compliant color contrasts and focus states
- 🏗️ **Modular Code** — Well-organized JavaScript blocks for easy maintenance

### Categories Included

- **Secondary (Class 9–10)** — Portal, exam forms, e-books, syllabus
- **Senior Secondary (Class 11–12)** — Intermediate portal, admission facilitation, teacher directory
- **Scholarships & Student Welfare** — NMMSS, Post Matric, Student Credit Card, NCC
- **Academic Resources & Administration** — Learning portals, HR systems, grievance redressal
- **UDISE+ Management** — School records, facilities, teacher & student modules
- **Student & Academic Services** — Bonafide forms, cyber safety, study materials

---

## 📖 Usage

### For End Users
Simply visit the live site, search for what you need, and click any link to navigate to official BSEB portals or resources.
